# Zork — The Great Underground Empire

A browser-based fan tribute to the classic 1981 Infocom text adventure.

## Play

Open `zork.html` in any modern browser. No server required.

## Features

- 24 rooms spanning the white house, forest, underground empire, maze, and more
- Text parser: `TAKE`, `DROP`, `EXAMINE`, `OPEN`, `MOVE`, `READ`, `ATTACK`, `PUT IN`, compass movement
- Light/dark mechanics — wander into darkness and a grue will find you
- 8 treasures to collect and deposit in the trophy case, for a maximum score of 184
- Troll combat, a trap door hidden under a rug, a locked grating, and a jeweled egg with a hidden canary inside
- Command history (↑↓ arrow keys)

## Commands

| Command | Description |
|---|---|
| `LOOK` / `L` | Describe your surroundings |
| `N` / `S` / `E` / `W` / `U` / `D` | Move in a direction |
| `TAKE <item>` / `TAKE ALL` | Pick up items |
| `DROP <item>` | Drop an item |
| `INVENTORY` / `I` | List carried items |
| `EXAMINE <item>` / `X` / `LOOK AT` | Examine something |
| `READ <item>` | Read an item |
| `OPEN` / `CLOSE <thing>` | Open or close things |
| `MOVE <thing>` | Move something out of the way |
| `LIGHT` / `TURN ON <lamp/torch>` | Light a light source |
| `EXTINGUISH` / `TURN OFF <lamp/torch>` | Put a light source out |
| `PUT <item> IN <container>` | Place item in container |
| `ATTACK <enemy>` | Fight an enemy |
| `SCORE` | Show your score |
| `VERBOSE` / `BRIEF` | Full room descriptions every time, or only on first visit (default) |
| `RESTART` | Start over |
